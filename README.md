# Начальные значения параметров обучаемых функций активации

Код, результаты и текст статьи **«Начальные значения параметров обучаемых функций активации: чувствительность обучения, пробные прогоны и перенос значений»** (К. М. Черников).

## Кратко
- **Обучаемые функции:** PReLU, Swish-β, ACON-C и предложенная **SigLin-T**: f(x) = n·σ(Bx) + L·x, у которой производная ограничена снизу числом L.
- **Чувствительность:** при ограниченном бюджете обучения (30 эпох) параметры крутизны функций меняются лишь на 1–11 %, поэтому начальные значения заметно влияют на качество.
- **Пробные прогоны:** короткие прогоны кандидатов значимо улучшают результат для PReLU и Swish-β.
- **Перенос:** значения, найденные на одних задачах (a = 0,01, β = 4), часто переносятся на другие без затрат. При смене класса задач лучше работает пробный прогон достаточной длины.
- **Сравнение с нормой:** при одинаковом числе эпох обучения пилот не хуже стандартной инициализации по всем 8 задачам. При равных вычислительных затратах выгоднее учить модель дольше.
- **SigLin-T в глубокой сети:** в сети 8×128 превосходит обычную сигмоиду во всех 20 сравнениях.

Всего 1805 обучений, 8 задач, 2 архитектуры.
